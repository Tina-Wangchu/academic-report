# Academic Skills

Academic paper search, analysis, and report generation skills for Hermes Agent.

## Skills

- **paper-email-service**: End-to-end orchestrator — multi-source search + AI analysis + HTML report + email delivery
- **paper-search**: Multi-source academic paper search engine (Semantic Scholar, arXiv, CrossRef, OpenAlex, PubMed)
- **paper-summarizer**: AI-powered paper analysis and summarization
- **report-generator**: Professional HTML academic report generation
- **email-sender**: Email delivery via SMTP (Gmail, QQ, 163, Outlook)
