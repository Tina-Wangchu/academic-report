#### 3. Scaling deep learning for materials discovery

- **作者 / Authors**: Amil Merchant, Simon Batzner, Samuel S. Schoenholz 等 / et al.
- **发表时间 / Published**: 2023
- **发表期刊 / Venue**: Nature
- **引用量 / Citations**: 1234
- **DOI / DOI**: 10.1038/s41586-023-06735-9
- **链接 / Link**: https://openalex.org/W4389132751

**解决的问题 / Problem**:
无机晶体发现长期受限于高成本、低通量的试错实验与合成瓶颈，其本质难点在于准确评估候选结构相对于竞争相 convex hull 的热力学稳定性（分解能），以突破人类化学直觉的局限。

**现有方案 / Existing approaches**:
1. 实验策略受制于成本与合成复杂性，无法扩展规模；2. 结合简单替换的 DFT 计算虽将稳定结构扩至约48000个，但通量仍受限；3. 现有机器学习技术在估算相对 convex hull 的稳定性时表现无效。

**新方案 / New approach**:
1. 提出大规模 active learning 框架 GNoME；2. 采用 symmetry-aware partial substitutions (SAPS) 与 random structure search 生成超10^9个多样化候选结构；3. 利用 state-of-the-art graph neural networks 过滤候选，并通过 DFT 计算验证以构建数据飞轮迭代训练。

**效果及局限性 / Results & limitations**:
发现220万个低于当前 convex hull 的稳定结构，使人类已知稳定材料规模扩大一个数量级，其中736个已被独立实验验证；衍生模型可实现高精度 zero-shot 预测离子电导率。约束：依赖 DFT 计算作为验证与数据飞轮的底层支撑，在更复杂的非平衡态或极端合成场景未验证。

**研究价值与应用 / Value & applications**:

**现有方案 / Existing approaches**:
